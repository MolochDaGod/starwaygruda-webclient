⭐ STARWAYGRUDA

The ultimate web-based MMO experience inspired by Star Wars Galaxies. Features authentic SWG profession system, radial menus, HAM bars, targeting, harvesting, and more!

LAUNCH GAME
Press G in-game to switch to Ground Mode with full SWG systems

Quick Start

  1. Open a terminal in this folder
  2. Run npm install (first time only)
  3. Run npm run dev to start the development server
  4. Open http://localhost:8081 in your browser
  5. Press G to switch to Ground Mode with SWG systems
