🪐 Planet Heightmap Generator

Purpose: Generate heightmap and texture files for all planets to fix 404 errors.

How to use:
  1. Click "Generate All Planets"
  2. Download each heightmap.png and texture.png
  3. Place files in public/planets/{planetname}/
  4. Commit and push to GitHub
⚠️ Important: These are procedurally generated placeholders. For authentic SWG terrain, extract actual .trn files from the game client.
