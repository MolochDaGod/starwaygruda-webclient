## 🐛 TROUBLESHOOTING

### "Game won't load"
- Make sure you're using `.html` NOT `.htm`
- Clear browser cache (Ctrl+Shift+Delete)
- Try incognito/private mode
- Check browser console (F12) for errors

### "Black screen"
- Wait 10-15 seconds for assets to load
- Check you have WebGL 2.0 support
- Try Chrome or Firefox

### "Controls don't work"
- Click on the game canvas to lock pointer
- Check that character creation is complete
- Press H for help menu

### "Can't see buildings"
- Teleport to center: Type `/tp 0 30 0` in chat
- Use minimap to navigate (bottom-right)

## 🔥 QUICK COMMANDS

**In Chat (bottom-left):**
- `/tp x y z` - Teleport to coordinates
- `/tp 0 30 0` - Go to city center
- `/tp 80 30 -80` - Go to starport
- `/tp -80 30 -80` - Go to cantina

**Keyboard Shortcuts:**
- **H** - Toggle help
- **T** - Fast travel menu
- **E** - Interact
- **ESC** - Close menus
